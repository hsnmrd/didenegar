# Device Management Dashboard

A single-page dashboard for monitoring, filtering, and managing network devices built with Next.js and TypeScript.

---

## Prerequisites

- **Node.js**: `v20` or higher
- **pnpm**: `v9` or higher

---

## Getting Started

### 1. Clone the repository

```bash
git clone git@github.com:hsnmrd/didenegar.git
cd didenegar
```

### 2. Install dependencies

```bash
pnpm install
```

### 3. Run the development server

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## Scripts

| Command                  | Description                                  |
| :----------------------- | :------------------------------------------- |
| `pnpm dev`               | Starts the development server with Turbopack |
| `pnpm build`             | Builds the production bundle                 |
| `pnpm start`             | Runs the production build locally            |
| `pnpm run lint`          | Runs ESLint checks                           |
| `pnpm exec tsc --noEmit` | Runs TypeScript type checking                |
